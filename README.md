# quasar-legal

Public privacy policy and support pages for Quasar, the Emby, Jellyfin and Feiniu client.

- Privacy policy: https://94mashiro.github.io/quasar-legal/privacy.html
- Support: https://94mashiro.github.io/quasar-legal/support.html

The iOS app links to the privacy policy from Settings > About. App Store Connect uses both URLs in App Information.

Plain static HTML, served by GitHub Pages from `main`. Update the effective date in `privacy.html` when the policy changes.
