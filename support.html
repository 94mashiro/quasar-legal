Common questions

I cannot connect to my server

Quasar is a client, not a server. Check that the address opens in a browser on the same device, that the server is running, and that the account can sign in to the server's own web interface.

Playback fails or shows a black screen

Try another source or another player core in Settings. If it still fails, send the media information shown on the player page and the server name.

Where are my server credentials stored?

On your device, in the iOS Keychain or Android Keystore-backed storage. They are sent only to the server address you entered. See the privacy policy.

How do I delete my data?

Remove the server in Settings to delete its credentials and cache. Disconnect Trakt to delete its tokens. Clear the MDBList key in Settings, or delete the app.

I forgot my server password

Contact the person who runs the server. Quasar cannot reset a server password.

This server has content I should not see

Quasar ships with no media and no server. All libraries come from servers that users add themselves.

常见问题

连不上服务器

Quasar 是客户端，不是服务器。先在同一台设备上用浏览器打开服务器地址，确认服务器在运行，账号能在服务器自己的网页端登录。

播放失败或黑屏

在设置里换一个片源或换一个播放内核。还是不行的话，把播放页显示的媒体信息和服务器名称发给我们。

账号密码存在哪里

只存在你的设备上，iOS 用钥匙串，Android 用 Keystore 加密存储，只发送到你填写的服务器地址。见隐私政策。

怎么删除数据

在设置里删除服务器，会删掉它的账号密码和缓存。断开 Trakt 会删掉令牌。在设置里清空 MDBList key，或者删除 App。

忘了服务器密码

请联系服务器管理员。Quasar 不能重置服务器密码。

服务器上有不该看的内容

Quasar 不附带任何媒体和服务器。所有媒体库都来自用户自己添加的服务器。
