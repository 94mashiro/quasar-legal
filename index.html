Privacy Policy / 隐私政策Support / 支持

About

Quasar lets you browse and play media from several personal media servers in one library. It ships with no media and no server. Every library comes from a server the user adds.

The app is published by an individual developer. There is no Quasar account and no developer-operated content service.
